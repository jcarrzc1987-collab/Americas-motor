# America's Motors

A website for America's Motors, a Corvette and exotic car rental shop in Phoenix, Arizona.

**Live site:** https://jcarrzc1987-collab.github.io/Americas-motor/

## Features
- Cinematic neon logo intro with Skip and Replay
- Fleet showcase of Corvettes and exotic cars
- Booking request form
- Fully responsive layout for phones, tablets and desktop

## Built with
- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (no frameworks)

## Run it locally
Download or clone this repository and open `index.html` in your browser.
